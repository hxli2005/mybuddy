# 导师自动演示合成记忆

本目录是受版本控制的合成演示基线，不是真实用户历史。

每次运行 `scripts/mentor_demo.ps1` 时，脚本都会把本目录复制到新的临时运行目录；
演示产生的聊天、`shown` 和日志不会回写本基线，也不会进入日常数据。

基线先保留前三天逐步形成的三条例证：

1. 表达习惯：先看具体例子，再听抽象总结；
2. 决策偏好：两个方案都能完成时选择更小、更直接的方案；
3. 内容兴趣：关注科幻中初次接触造成的误解；
4. 生活观察保持空白，自动演示会通过一轮真实聊天当场形成。

已有用户事实都保留合成原话、来源时间、记忆操作和当时的直接回应。演示随后发送
一条老建筑偏好，页面应立即显示空槽被填入；下一句“你好”再证明这条新记忆被主动激活。
