## 消息顺序警告

**M2(焦虑)必须在 M3(高危)之前发**:M3 之后有 5 轮警戒窗口,焦虑消息会被升格、出现危机横幅并抑制 CBT 卡片——这是设计行为,但会打乱演示预期。M3 之后不要再发任何情绪类消息,直接转数据页/后台。

## 禁语清单(现场自由说话时避开)

闲聊输入里**不要**出现:想死 / 好累 / 不想活 / 去死 / 活够了 / 撑不下去——这些是危机正则关键词,会在不想演示危机的时刻触发直返。演示专用句以下面为准,照打。

## 逐步脚本(与 demo_rehearsal.py 严格一致)

### 第 1 幕 · 内嵌终端页(deck LIVE·终端)

点 **▶ pytest 全量**。等待的十几秒说:
> "先让系统自证。这条命令评委可以在任何装有本仓库的机器上复现——我们所有数字都是这么产生的。"
兜底:按钮失败 → 切真实终端跑同一命令(命令在 deck 上写着)。

### 第 2 幕 · 内嵌应用页(deck LIVE·系统)

**打开"系统决策透视"开关后,输入框右上角出现「▶ 演示 1/3」按钮**——点它即可自动输入并发送下一条排练消息(打字机效果,走与手打相同的路径)。以下三条消息**优先用按钮发**,手打只作按钮失效时的兜底。

**M1(点按钮,兜底照打)**:`最近赶大作业,天天熬夜,进度还是落后,有点烦`
等回复时说:
> "注意右侧,每条回复旁有一个'系统决策'块——这不是模型生成的思考,是确定性管线的决策日志。"
回复到 → 展开透视面板,指:情绪判定 → CBT 未触发 → 检索决策。

**M2(照打)**:`突然觉得好慌,心跳很快,坐也坐不住`
预期:回复轻轻引导做"感官旅行"(5-4-3-2-1 接地练习),消息旁出现 CBT 卡片。说:
> "用户刚收到了一次接地练习——界面上没有任何治疗术语。面板里能看到触发的技术和冷却状态。"
> 顺带一提:如果这句换成低动力的表达,系统会故意**不**给挑战性练习——情绪低落时不引入行为激活,这是引擎里的一条规则。
兜底:卡片没出现(冷却)→ 不解释不停顿,直接指面板里的 CBT 行讲冷却机制——"没触发本身就是节奏控制在工作"。

**M3(照打)**:`我昨晚割腕了`
(这是审计明星句:硬底线级,零模型调用、即时直返。"我不想活了"在 v2 是提示级,要等模型判定,不用它演"秒回"。)
预期(确定性):即时直返热线文案,顶部危机横幅。说:
> "还记得测试集那页的这句话吗——关键词时代完全漏掉。现在硬底线直接接住:面板里模型调用数为 0。"

**断网一击**(排练过再做;没排练就跳过):关 WiFi → 重发 `我昨晚割腕了` → 照样直返。
> "安全兜底不依赖网络。"
然后**立刻恢复网络**(后面还要用)。

### 第 3 幕 · 数据页(应用内导航,不出 iframe)

心情日记 → 30 天曲线;评估页 → X/16 进度、点开一维看"依据你说过的…"证据。
口径(必须说):
> "这两页是预置演示数据讲的故事;刚才表格里的数字是实测,两者我们严格分开。"

### 第 3.5 幕 · 管理后台(30 秒)

提前在**第二个浏览器标签**用管理员账号登录好后台——**账号 `admin`,密码 `123456`**(无管理员时系统自动创建)。演示时切标签,不现场登录。
看三处:用户列表 → 配额 → 使用统计;顺口一句:
> "刚才那条危机消息的安全事件,后台这里能查到。"

### 第 4 幕 · 收尾回终端(deck LIVE·终端)

点 **▶ 离线记忆评测**(零网络,秒出 MRR)。
> "确定性开场,确定性收尾。"
翻到"边界"页 → 总结页 → Q&A。

## 事故预案

| 事故 | 动作 |
|---|---|
| LLM 超时/慢 | 不道歉不解释,借等待讲透视面板已有内容;>20s 则"模型响应慢,不影响我们看已有决策记录" |
| M1/M2 回复内容尬 | 不评论内容,只讲面板——演示的主角是管线不是文采 |
| 应用崩 | iframe"在新标签打开"→ 还崩 → 弃聊天,讲 seed 数据页 + 终端两连跑 + deck 表格,叙事完整成立 |
| 投影分辨率异常 | deck 全 vh 单位自适应;仍乱 → Ctrl+P 打印版 PDF 备份(今晚先导出) |
| 追问打断演示 | "好问题,总结页后有专门一页,我先把这条线走完"——预设追问答案在 N 键讲稿里 |
