01  问题MyBuddy

大多数心理困扰,发生在"不会去求助"的人身上

现有三种选择,各缺一角——中间层是空的

现状 A
独自硬扛
病耻感与求助门槛,情绪困扰长期无人察觉、无人记录——直到危机才被看见
现状 B
通用聊天 AI
能聊,但不可靠:危机时刻可能说错话、无持续观测、无安全兜底、聊完即忘
现状 C
专业渠道
有效,但覆盖不足:预约、费用、心理门槛——不适合"还没准备好求助"的大多数

 ·  (数字须核实来源后填入,宁缺毋滥)

我们的定位:不诊断 · 不开药 · 不替代治疗。做中间层——倾诉出口 + 无感持续筛查(早发现) + 循证自助练习 + 危机时刻可靠转介。

60 秒。此页回答"解决什么问题":让"还没准备好求助的人"有一个安全的落脚点,并在需要时把他推向专业资源。统计槽建议来源:WHO Depression fact sheet;《中国国民心理健康发展报告》——今晚核实后填,核实不了就删掉该行。
02  为什么难MyBuddy

这个中间层难做,难在四个结构性矛盾

"聊天机器人 + 温柔人设"补不了这一层——每个矛盾都要求专门的系统设计

矛盾 01 · 安全
用户最需要帮助的时刻,恰是系统最不能出错的时刻
生成式模型本质是概率的 → 风险越高模型话语权越小;最高危时模型被摘出回路
矛盾 02 · 观测
筛查需要数据,但"被评估感"杀死倾诉
没人对着朋友填量表 → 把 PHQ-9 / GAD-7 拆成 16 维状态机,溶进闲聊
矛盾 03 · 干预
自助练习有效的前提,是不被察觉是干预
说教感是陪伴的死因 → CBT 技术伪装成游戏,节奏受冷却与情绪门控约束
矛盾 04 · 关系
陪伴是一段关系,不是一串问答
请求-响应架构"你不说话我就不存在" → 延迟关怀、沉默跟进、夜间记忆整理
每条 20 秒:先念矛盾让评委点头"确实难",再一句答案。技术细节留给后面三页。

04  设计一 · 安全MyBuddy

风险越高,越不信任大模型——高危路径零生成

对用户意味着:说出危险信号的人一定被接住;求助与科普的提问不再被误拦在门外。

  • 硬底线(正则):只收录"子串即语义"的无歧义表达,命中即确定性直返热线,跳过一切 LLM——模型宕机、提示注入都拦得住
  • 语言层:风险判定并入每轮已有的情绪调用(带 8 条上下文),处理否定 / 反讽 / 第三人称 / 委婉语 / 康复叙述
  • 融合不对称:LLM 可否决提示级正则(治误伤),不能否决硬底线(保漏判);LLM 不可用 → 保守退化为纯正则
  • 警戒窗口:任一轮 ≥HIGH 后 5 轮内自动提高敏感度

同一标注集上的架构消融(n=,14 个对抗桶)

每轮旁路 LLM 调用:v1 ≤3 次 → v2 1 次 · 对抗桶来自对自身正则层的代码审计(错误驱动构造,不是随机采样)。

金句:"我们对模型的信任是随风险递减的函数。"追问"为什么不训练分类器":安全场景要求可审计的确定性兜底;百级标注下零样本小模型强于自训;蒸馏本地分类器列为下一步——落在您的领域。
05  设计二 · 筛查MyBuddy

把一次性问卷,改造成分布式异步采样协议

对用户意味着:两周日常聊天 ≈ 一次标准量表筛查——零填表负担,变化被更早发现。

  • PHQ-9 + GAD-7 = 16 维独立状态机:unasked → asked → scored;14 天过期回退;周期归档
  • 投放节流:两次自然提问 ≥3 轮间隔;自伤维度永不主动投放——伦理红线内置于状态机
  • 自由文本 → Likert 0-3 由小模型翻译;只接受待评分维度(白名单防幻觉记分)
  • 集齐 16 维自动出总分 / 严重度 / 历史曲线,计分与标准量表完全兼容

效标效度:预测总分 vs 真值(n= 人物 × 2 量表,实测 2026-07-30)

加权 kappa · 总分 MAE · 严重度一致 · 闲聊误记 · 覆盖中位 轮 —— 真值由构造给定,回答刻意口语化。

追问"LLM 打分凭什么可信"→ 指右表。PHQ-9/GAD-7 信效度由临床文献确立,我们只验证自己的翻译层——正确的验证边界。
06  设计三 · 陪伴MyBuddy

一次情绪检测,驱动四条链路

对用户意味着:被记住、被惦记的陪伴和循证练习——却没有"被治疗"的感觉。

  • 回应策略:15 类情绪 → 各自的镜映 / 需求 / 引导 / 小行动;明令禁止"我理解你"固定三段式
  • 主动关怀:连续 2 轮负面 → 30 分钟后的延迟问候(刻意不即时)
  • 心情日记零输入:每轮自动推导 0-10 分落库 → 趋势 / 分布 / 连续天数被动生成
  • CBT 触发门:五种技术伪装成游戏("拆弹""感官旅行"),24h 冷却持久化;危机中风险以上通道关闭

10  边界MyBuddy

诚实的边界

主动讲,不等追问

局限

  • 标注集 gold 为团队审校版,未经临床专家背书;高危漏报声明是"置信上界",不是"零漏报"
  • 抽取管线在 LoCoMo 上曾得 0.267 的负向结果(中英语种错配)——定性为方法学存档,不作能力声明
  • 输出审核存在误伤面(如否定式用药劝阻),已量化,列入修复清单
  • 演示故事数据与实测数据全程分开标注

下一步

  • 蒸馏本地小分类器替换级联语言层——零网络依赖的完整安全闭环
  • 高危样本扩至 n≈300,漏报置信上界收紧到 1%
  • 真实用户数据需伦理审查流程,课程阶段不采集
学术评委吃"自曝边界"。蒸馏分类器放最后说——落在老师领域,是把冷淡变兴趣的钩子。
11  总结MyBuddy

回到最初的问题:大多数人在"独自硬扛"和"专业求助"之间,没有落脚点。

小布补的就是这一层。而这一层必须安全——所以大模型只负责说话;什么时候说、朝什么方向说、什么时候不许它说,由确定性系统决定,并由数据集背书。

换掉底层模型,这个系统依然成立。
